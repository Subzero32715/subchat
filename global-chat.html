⚙ Setup guide — required to make this work online

1. Create a free Supabase project

Open supabase.com, create an account and a project. In your project, open Project Settings → API (or the Connect dialog) and copy the Project URL and the publishable/anon key.

2. Paste your public project settings into this file

Near the bottom of this HTML, find SUPABASE_URL and SUPABASE_ANON_KEY. Replace the placeholder strings with your project's values. These browser values are public by design; never put a service-role key in this file.

3. Create the database tables and security rules

In Supabase, open SQL Editor → New query, paste the SQL shown below, and click Run. It creates a profile table, a public messages table, and row-level security policies.

create table if not exists public.profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  username text not null unique check (char_length(username) between 2 and 24)
);

create table if not exists public.messages (
  id bigint generated always as identity primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  username text not null,
  body text not null check (char_length(body) between 1 and 1000),
  created_at timestamptz not null default now()
);

alter table public.profiles enable row level security;
alter table public.messages enable row level security;

create policy "Profiles readable by signed-in users"
on public.profiles for select to authenticated using (true);

create policy "Users can insert their own profile"
on public.profiles for insert to authenticated
with check (auth.uid() = id);

create policy "Users can update their own profile"
on public.profiles for update to authenticated
using (auth.uid() = id) with check (auth.uid() = id);

create policy "Signed-in users can read messages"
on public.messages for select to authenticated using (true);

create policy "Signed-in users can send messages as themselves"
on public.messages for insert to authenticated
with check (
  auth.uid() = user_id
  and exists (
    select 1 from public.profiles p
    where p.id = auth.uid() and p.username = messages.username
  )
);

-- Turn on Realtime for the messages table.
alter publication supabase_realtime add table public.messages;

4. Host the HTML online

Save this as index.html and publish it using a static host such as GitHub Pages. The HTML must be hosted on a web address for other people to use it. In Supabase Authentication settings, configure the site's URL and allowed redirect URLs to match your published site.

Important: This starter is a public room, not private messaging. Add moderation, reporting, rate limits and stronger username validation before sharing widely. Configure Supabase email confirmation as desired. The starter requires email/password authentication.
